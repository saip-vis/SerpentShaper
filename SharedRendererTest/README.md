# Shared-shape renderer pilot

Open `SharedRendererTest/index.html` to try the standalone shape lab. It uses a single, simplified top-down pose and a common set of continuous controls for head width and length, body width, hood expansion, diamond and hood markings, rattle, and tail taper. Reference weights are normalized; the three hand-authored reference-inspired examples are a western diamondback, monocled cobra, and black mamba. Change a reference slider to update the blended controls; adjust any individual control manually; use **Reset to blend** to discard manual refinements. Changing reference weights also resets manual refinements. SVG export includes the effective controls, reference weights, and manually edited fields as metadata.

## Scope and evidence

The example values and projected pose are **artistic design parameters**, not morphometric measurements, species identification, or a validated biological or venom-to-phenotype model. The starting values were hand-authored using the project's existing illustrative presets and qualitative notes, not fit from photos or generated by an ML model. The neutral top-down pose deliberately differs from the existing raised cobra drawing and does not reconstruct other views. Photos and venom profiles are not known to belong to the same individual. The images and sources can guide later refinements, but this prototype does not establish that one feature causes or predicts another.

Reference documentation:

- `config/species_presets/crotalus_atrox.json` and `data/image_pilots/pilot_004_western_diamondback/manifest.json`
- `config/species_presets/naja_kaouthia.json` and `data/image_pilots/pilot_108_naja_kaouthia/manifest.json`
- `config/species_presets/dendroaspis_polylepis.json` and `data/image_pilots/pilot_003_black_mamba/manifest.json`

Not every photo has been approved for training or verified as a healthy correctly identified specimen. The lab does not load or redistribute photos, and it does not change their review status. The western diamondback photo flagged for possible injury in `ML/image_traits/README.md` was not used in this prototype.

The lab itself is a separate, manually controlled illustration experiment. It does not replace the existing species-specific SVG renderings. The main venom interface now offers an optional **Shared-shape pilot** that uses these same three designs and compares the entered venom against their source profiles; see `MainInterface/README.md` for its scoring and limitations. There is no image-trained model here. The next step is to review whether the controls and intermediate shapes are useful, refine their geometry, and expand the evidence; only after that should a trained model be compared against a simple reference-blend baseline.

## Verify

Run `node --test SharedRendererTest/shared-morphology.test.cjs` from the repository root. The checks exercise reference-weight normalization, continuous changes in all controls across a diamondback/cobra blend, finite closed body paths, manual refinements, reset, and the no-reference state. These are software checks, not evidence of biological accuracy or a substitute for visual review.
